# 株洲体育中心智慧管理平台设计系统

本文件是后台视觉与交互的全局来源。页面级规则如需偏离，应在 `design-system/pages/` 中说明覆盖原因。

## 设计原则

- 政务可信：信息层级清晰、正文对比度至少达到 WCAG AA，状态不只依赖颜色表达。
- 科技克制：深海军蓝基底、科技蓝与青色高光；玻璃模糊只用于侧栏、顶栏和重点卡片。
- 高效稳定：动效限于 150–250ms 的 opacity/transform/颜色过渡，不使用粒子、持续装饰动画或布局位移动画。
- 中文优先：使用苹方、微软雅黑、Noto Sans CJK SC 与系统无衬线字体，不加载外部字体资源。
- 模板中不预设任何业务模块、指标、菜单或数据模型；业务内容仅在需求明确后逐项加入。

## 主题令牌

- 深色：背景 `#020617`，卡片 `#0B1324`，主色 `#38BDF8`，青色 `#22D3EE`，正文 `#F8FAFC`。
- 亮色：背景 `#F8FAFC`，卡片 `#FFFFFF`，主色 `#0369A1`，正文 `#0F172A`，弱化正文不浅于 `#475569`。
- 状态：success、warning、info、danger 必须同时配合文字或图标。
- 圆角：组件 8–12px，重点容器 12–16px；统一使用主题变量，不单独发明圆角。

## 玻璃与层级

- 模糊半径默认 16px，亮色玻璃不透明度不低于 84%，深色不低于 72%。
- 玻璃容器必须带可见边框；浏览器不支持 `backdrop-filter` 时降级为高不透明度纯色卡片。
- 不在同一视觉区域堆叠超过两层玻璃；普通列表行使用半透明填充而不重复模糊。

## 交互与无障碍

- 所有按钮、菜单和可点击卡片提供 hover、focus-visible 和 disabled 状态，点击区域不小于 44px。
- 后台侧边导航使用单列布局，不提供桌面端折叠；路由按模块使用标题与分隔线分组。
- 当前路由项同时使用左侧高亮线、背景和文字变化标识，不只依赖颜色。
- 表单使用真实 Label、字段级错误、autocomplete 与 aria-live；首个错误字段自动获得焦点。
- 图标统一使用 Lucide SVG，装饰图标隐藏于读屏，不使用 Emoji 作为界面图标。
- 尊重 `prefers-reduced-motion`；导航密集页提供跳过导航链接。

## 响应式与性能

- 平台仅支持 PC 端，最低有效视口宽度为 `1024px`；小于该宽度时只显示统一的电脑端访问提示，不挂载登录、后台路由、地图 SDK 或业务页面。
- 重点验收 `1024px`、`1280px`、`1440px`、`1920px`；不为手机和平板维护导航、表格、弹窗或业务交互布局。
- 后台侧栏在所有受支持视口固定显示完整单列导航，不提供折叠、抽屉或收起功能。
- 页面使用 CSS 渐变与内联 SVG，不使用远程图片、视频或重型图表库。
- 页面路由懒加载，视觉动效使用原生 SVG，动画仅修改 transform 与 opacity。
- 登录页大屏左侧仅使用抽象 SVG 科技视觉，不承载功能描述、推测性业务信息或宣传指标。

## 禁止项

- 紫粉 AI 渐变、赛博朋克故障效果、低对比霓虹字和无意义持续动画。
- 仅靠颜色传达告警、移除焦点轮廓、使用没有可访问名称的图标按钮。
- 在亮色主题使用过低不透明度玻璃，或在表格和高密度列表逐项使用 backdrop blur。
